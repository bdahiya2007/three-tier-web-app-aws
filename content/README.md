# Blog content backup

`content/wordpress/` is generated by [`scripts/wp_content.py`](../scripts/wp_content.py) — don't edit it by hand. The weekly `content-backup.yml` workflow exports the published content of https://blog.securecloudengineers.com and opens a PR when it has changed.

| Path | What |
|---|---|
| `posts/<slug>/`, `pages/<slug>/` | `content.html` (raw block-editor markup) + `meta.json` (title, date, categories, tags, featured image, parent) |
| `media/` + `media.json` | Uploaded files and their title/alt text/caption |
| `categories.json`, `tags.json` | Terms, with parent relationships |
| `templates/`, `template-parts/`, `global-styles.json` | Site-editor customizations only (e.g. an edited footer), not theme defaults |
| `blocks/`, `navigation/` | Reusable blocks and navigation menus |
| `settings.json` | Site title, tagline, timezone, reading settings (no admin email) |

Only **published** content is exported — no users, emails, comments, drafts or database dump — because this repository is public.

To rebuild the blog on a new site, see "Blog content backup and restore" in [Deployment.md](../Deployment.md).
